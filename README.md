## 📌 Sobre o Projeto

Portfólio online pessoal desenvolvido como **Atividade Prática** da disciplina **Fundamentos da Programação Web** — Uninter.

O site apresenta informações profissionais, formação acadêmica, projetos desenvolvidos e um formulário de contato, com suporte a dois idiomas (PT/EN).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura semântica do conteúdo
- **CSS3** — estilização customizada (sem frameworks)
- **JavaScript** — interatividade, validação de formulário e alternância de idioma

> Nenhum framework foi utilizado (sem Bootstrap, React, jQuery, etc.), conforme requisitos da atividade.

## ⚙️ Funcionalidades JavaScript

- **Alternância de idioma** — botão PT/EN troca todo o conteúdo do site dinamicamente
- **Validação de formulário** — verifica campos obrigatórios e formato de e-mail antes do envio
- **Scroll reveal** — seções aparecem com animação ao rolar a página
- **Nav ativa** — link do menu destaca a seção atual automaticamente
